# OS Practice Questions — CS222 Operating Systems

**English** · [العربية](#العربية)

An interactive question bank built from past CS222 (Operating Systems) exams, midterms and quizzes at Imam Mohammad Ibn Saud Islamic University.

- **740 unique questions**, sorted by lecture chapter (Ch 1, 3, 4, 5, 6, 7, 8, 9, 10, 13, plus textbook topics outside the slides).
- Every question is **solved and explained**, and shows the **exam it came from** and the **lecture slide** it is based on.
- Questions in each chapter run **from the newest exam to the oldest**.
- One question per page with **Prev / Next**, a **shuffle** option, a question‑type filter, and progress saved in your browser.

## How to use

1. Download or clone the repository.
2. Open `index.html` in any browser. No installation or server is needed.
3. Pick a chapter (or "All chapters"), answer, then press **Next**.

Keyboard: `←` `→` move between questions, `1`–`6` choose an option, `Enter` shows the solution.

## Files

| File | Purpose |
|---|---|
| `index.html` | The website |
| `questions.js` | All questions, answers, explanations and sources |
| `img/` | Figures cropped from the exam papers |
| `page.html` | Same page without the HTML wrapper (used for the hosted version) |

> Answers were checked by hand and with a small simulator for scheduling, Banker's algorithm and page replacement. Where an original key looked wrong, the explanation says so.

## العربية

بنك أسئلة تفاعلي لمقرر **CS222 نظم التشغيل** مبني من اختبارات النهائي والميدترم والكويزات السابقة في جامعة الإمام محمد بن سعود الإسلامية.

- **740 سؤالًا** بدون تكرار، مرتبة حسب فصول المحاضرات (الفصول 1، 3، 4، 5، 6، 7، 8، 9، 10، 13، إضافة إلى مواضيع من الكتاب غير موجودة في الشرائح).
- كل سؤال **محلول مع شرح لطريقة الحل**، ويوضح **الاختبار الذي جاء منه** و**رقم الشريحة** في المحاضرة.
- الأسئلة في كل فصل مرتبة **من أحدث اختبار إلى الأقدم**.
- سؤال واحد في كل صفحة مع زر **التالي / السابق**، وخيار **خلط الأسئلة**، وتصفية حسب نوع السؤال، وحفظ تقدمك في المتصفح.

### طريقة الاستخدام

1. حمّل المستودع أو انسخه.
2. افتح ملف `index.html` في أي متصفح، لا يحتاج تثبيت أو خادم.
3. اختر فصلًا (أو "All chapters")، أجب على السؤال، ثم اضغط **Next**.

لوحة المفاتيح: الأسهم `←` `→` للتنقل، الأرقام `1`–`6` لاختيار الإجابة، و`Enter` لعرض الحل.

### الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع |
| `questions.js` | جميع الأسئلة والإجابات والشروحات والمصادر |
| `img/` | صور مقتطعة من أوراق الاختبارات |
| `page.html` | نفس الصفحة بدون الغلاف (للنسخة المستضافة) |

> تم التحقق من الإجابات يدويًا وبمحاكي بسيط لمسائل الجدولة وخوارزمية المصرفي واستبدال الصفحات، وإذا كان الحل الأصلي خاطئًا فالشرح يوضح ذلك.
